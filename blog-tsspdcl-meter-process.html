TSSPDCL Guide

TSSPDCL New Meter Connection: Process in Hyderabad

  1. Fix load (KW) + single/3-phase + wiring + earthing ready
  2. Documents: ownership, ID, NOC if tenant, previous bill if any
  3. Online application + estimate + meter cost payment
  4. Section officer inspection → meter fixing → seal + release

Time: 7–21 days if wiring-ready. Apartments: apply together with meter board numbering to avoid re-visits.
